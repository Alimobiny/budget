# 🫙 سیستم بودجه شخصی — تک‌نفره

وب‌اپ تعاملی فارسی (راست‌به‌چپ) برای دسته‌بندی هزینه‌های شخصی، مدیریت صندوق‌های دوره‌ای، تأمین صندوق اضطراری و تخصیص اصولی درآمد.

**تک‌فایل و بدون وابستگی:** فقط یک فایل `index.html` — بدون سرور، بدون فریم‌ورک، بدون مرحله ساخت.

## امکانات

- 🏠 **داشبورد** — نمای زنده کل وضعیت بودجه
- 🗂️ **۱۲ دسته هزینه** با سبدبندی نیازها / خواسته‌ها / پس‌انداز
- 🫙 **صندوق‌های دوره‌ای** (Sinking Funds) — سهم ماهانه = هدف سالانه تقسیم بر ۱۲
- 🚨 **صندوق اضطراری** — هدف ۳ تا ۱۲ ماه هزینه ضروری با نوار پیشرفت
- ⚖️ **قاعده ۵۰/۳۰/۲۰** — اسلایدرهای زنده و مقایسه با تخصیص واقعی + نمودار دونات
- 🏦 **معماری حساب‌ها** — دیاگرام تعاملی روش «شیشه‌های مربا» (Jam Jar)
- 🛡️🚀 **دو رویکرد** محافظه‌کارانه و تهاجمی‌تر
- ✅ **هفت گام تخصیص درآمد** با محاسبه زنده مبالغ
- 🖨️ **چاپ A4** — تک‌بخش، چاپ کامل، و برگه خلاصه یک‌صفحه‌ای با تاریخ شمسی
- 💱 **تبدیل تومان↔ریال** — جابه‌جایی واحد، خودِ مبالغ را هم ×۱۰/÷۱۰ تبدیل می‌کند تا ارزش واقعی ثابت بماند (دلار فقط برچسب واحد است)

## حریم خصوصی

همه داده‌ها فقط در حافظه محلی مرورگر خود شما (`localStorage`) ذخیره می‌شوند و هیچ داده‌ای به هیچ سروری ارسال نمی‌شود.

## اجرا

فایل `index.html` را در مرورگر باز کنید — یا از نسخه منتشر‌شده روی گیت‌هاب پیجز استفاده کنید.

## فناوری

جاوااسکریپت خالص، نمودارهای SVG دست‌ساز، فونت وزیرمتن (با جایگزین تاهوما در حالت آفلاین)، قالب چاپ `@page A4`.
